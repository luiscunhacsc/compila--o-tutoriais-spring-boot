# 🚀 Tutoriais Spring Boot – Do Zero à Prática Real

Este repositório reúne **tutoriais práticos e diretos ao ponto** sobre o desenvolvimento de aplicações web com **Spring Boot**, com foco em arquitetura limpa, boas práticas e integração com **React.js** no frontend.

> 📘 Todos os tutoriais são em **português de Portugal (PT-PT)** e foram pensados para ser fáceis de seguir, mesmo que estejas a começar do zero.

---

## 📦 O que vais encontrar aqui

Cada tutorial está organizado em PDF com explicações passo a passo, trechos de código e analogias pedagógicas. Entre os temas já disponíveis ou em preparação, incluem-se:

- ✅ Criação de aplicações Spring Boot com o Spring Initializr
- ✅ Estrutura de projeto: controller, service, repository, model
- ✅ Integração com React.js usando Axios
- ✅ CRUD completo (Create, Read, Update, Delete)
- 🔒 Autenticação com Spring Security e JWT
- 🧪 Testes com JUnit, Mockito e MockMvc
- 🐳 Deploy com Docker e Heroku
- 🧭 Monitorização com Actuator e Prometheus
- 🧠 Dicas cognitivas para aprender mais rápido e melhor

---

## 🧩 Tecnologias Usadas

### Backend
- **Spring Boot**
- **Spring Data JPA**
- **H2 / MariaDB**
- **Spring Security**
- **Maven**

### Frontend
- **React.js** com Hooks
- **Axios** para chamadas API
- **React Router**
- *(Brevemente)* **Material UI (MUI)** para design profissional

## 📚 Começar

1. Acede ao [Spring Initializr](https://start.spring.io)
2. Gera o teu projeto com `Spring Web`, `Spring Data JPA`, `H2 Database` e `Lombok`
3. Segue os tutoriais PDF deste repositório 🎯
4. Usa o `React.js` no frontend para consumir os endpoints REST
